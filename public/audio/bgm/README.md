# BGM 配置場所

Suno で制作した音源をこのフォルダに置くと、ゲームが自動で再生します。
ファイルが無い間は無音(効果音のみ)で動作します。

| ファイル名 | 用途 | 長さの目安 | ループ |
|---|---|---|---|
| `title.mp3` | タイトル画面 | 40〜90秒 | する(自動) |
| `world.mp3` | 通常戦闘(WORLD 1) | 45〜90秒 | する(自動) |
| `boss.mp3` | ボス戦 | 45〜90秒 | する(自動) |
| `clear.mp3` | ステージクリアジングル | 2〜8秒 | しない |
| `treasure.mp3` | 宝箱/ごほうびジングル | 2〜8秒 | しない |

- Sunoプロンプトは `doc/kanji_rpg_audio_spec.md` §9 のテンプレートを使用
- ループはコード側で `loop=true` にしているだけなので、**曲の頭と終わりが自然につながるように**中間部を切り出しておくと良い(仕様 §10.3)
- LISTENING(こども が しゃべる時間)中は自動で音量が 75% に下がる(仕様 §17.2)
